# 养个爬

本地优先的爬宠繁育管理工具。**所有数据只存在你自己的设备上**（浏览器 IndexedDB），不上传任何服务器；跨设备迁移通过**本地备份包**完成（JSON / Excel 格式可选，v2.2 起数据表导出统一为 Excel）。电脑 Web 端即开即用，预留 Capacitor 套壳能力打包为安卓 / iOS App，业务逻辑与备份格式完全一致。

首期核心物种：**睫角守宫、猪鼻蛇**（架构预留自定义物种）。

> 📦 **GitHub 仓库**：https://github.com/LethaZ-GitHub/reptile-breeding （公开，Apache-2.0 + The Commons Clause）
> 本地推送走 SSH（`ssh.github.com:443`）；HTTPS 通道在本机网络不可用。

## 一、快速开始

### 电脑 Web 端（零依赖，双击即用）

```
双击 start.bat                 # Windows 一键启动（自动寻找 Node.js）
                              # 启动后自动弹出浏览器；不想弹：--no-open
浏览器访问 http://localhost:3000（未自动打开时手动访问）
```

其他方式：

```bash
node server.js                 # 或
node server.js --port=3001     # 换端口
node server.js --no-open       # 启动但不自动打开浏览器
powershell -File start.ps1 -Port 3000 -Diagnose   # 带环境诊断
```

要求：Node.js 22+（仅用于本地静态服务；不装任何 npm 依赖）。数据存于浏览器本地，关闭浏览器不丢失；换电脑/换浏览器用「备份与恢复」迁移。

### 手机 App 端（两条路线）

**路线 A：PWA 装到主屏（零门槛，现在就能用）**

本应用是完整 PWA：手机与电脑在同一局域网时，浏览器访问电脑的 IP（如 `http://192.168.x.x:3000`），然后

- 安卓 Chrome：菜单 →「安装应用 / 添加到主屏幕」（应用内「设置 → 安装到手机」有引导和一键安装按钮）
- iPhone Safari：底部分享按钮 →「添加到主屏幕」

装好后全屏独立运行，离线可用，数据在设备本地，与电脑端备份包通用。

**路线 B：Capacitor 打包原生 APK（已在本机从零装机并成功出包）**

本机（Windows）已装好完整工具链并验证出包：JDK 17 + Android SDK（platform-tools / platform-35 / build-tools 35.0.0）+ Gradle 8.2.1（wrapper 走腾讯云镜像）。`build-apk.bat` 会**自动探测**工具链位置（优先 `JAVA_HOME` / `ANDROID_HOME` 环境变量，其次用户目录下的本地安装，最后回退 `C:\rb-build` 布局）。日常打包：

```
双击 build-apk.bat               # 自动：同步 www → cap sync → 同步工程到 C:\rb-build\project → gradlew assembleDebug → 拷贝 APK
```

产物在项目根目录：`app-debug.apk`（约 4.2MB，minSdk 22 / targetSdk 35，包名 `com.reptile.breeding`；**v1.0.0 首个正式版交付包已重命名为 `养个爬-1.0-debug.apk`，versionCode 28 / versionName 1.0**），传手机安装需允许「安装未知来源应用」。项目根目录**只保留最近三个版本的 APK**（当前为 3.4 / 3.5 / 1.0），更早的历史包已清理（可用源码随时重新构建）。

> **v3.4 起应用图标来源统一**：APK 图标与电脑端 exe 安装包图标均由 `tools/make-app-icons.py` 从工作空间根目录 `icon.png` 生成（各密度 mipmap + 自适应图标前景层 + 根目录 `icon.ico`）；导航页顶栏 / 侧栏 logo 与安卓启动页 logo 则统一由工作空间根目录 `logo-g.png` 生成（`www/icons/logo-g.png` 与 `res/drawable-nodpi/splash_logo.png`）。改图标只需替换工作空间的这两张源图后重跑 `py tools/make-app-icons.py` 与 `build-apk.bat`。
>
> **v3.5 起 APK 采用自适应图标**：`icon.png` 的渐变底纹被拟合成 `mipmap-*/ic_launcher_bg.png`（自适应图标背景层），其中的白色守宫剪影输出为 `mipmap-*/ic_launcher_foreground.png`（前景层），二者由 `mipmap-anydpi-v26/ic_launcher.xml` 与 `ic_launcher_round.xml` 组合为圆角/圆形自适应图标；旧设备仍回落到同色系传统 mipmap 图标。
>
> **v1.0.0 起图标主体严格居中**：守宫遮罩改用**连通域取最大块**剔除透明区抗锯齿杂块（干净 bbox 242,405,1794,1663），前景层按** alpha 加权质心（视觉重心）**而非 bbox 中心对齐画布 —— 趴姿守宫的 bbox 中心比视觉重心低约 90px（原图尺度），按 bbox 居中会让主体在圆形裁切后明显偏左上。脚本同时输出 `.tmp/icon-preview/adaptive-circle.png` 便于目视确认。

换电脑/重装时：

```
双击 install-build-env.bat       # 一键安装 JDK 17 + Android SDK 到 C:\rb-build（幂等，可重复执行）
双击 build-apk.bat               # 再执行打包（已装用户目录工具链时可跳过上一步）
```

> **中文路径构建说明（重要）**：项目位于含中文的路径（当前为 `G:\AI工作区\...`），Gradle 8.2.1 在该路径下会因 `sun.jnu.encoding` 把项目路径按 GBK 拼错（实测报 `Cannot snapshot ... not a regular file`），脚本缓存与 SDK 路径校验也会出 `IOException`，因此构建统一在纯英文路径 `C:\rb-build\project` 进行（脚本自动同步，排除 `.gradle`/`build` 等含绝对路径缓存的目录）。两个 `.bat` 脚本必须保持**纯 ASCII 内容**——cmd.exe 按 GBK 代码页解析 bat，中文字面量会导致命令错乱（`echo`/`copy` 的目标路径同样不能写中文字面量，须经 `%~dp0` 等变量注入）。另注意 cmd 的 `copy` 源路径**必须用反斜杠**（正斜杠报「系统找不到指定的文件」）；robocopy 退出码 <8 均为成功（0=无需复制、1=已复制、3=已复制并清理了目标端多余文件），只有 ≥8 才是真失败。
>
> **Release 签名**：正式发布需生成签名密钥（`keytool -genkey -v -keystore reptile.keystore -alias reptile -keyalg RSA -keysize 2048 -validity 10000`）并在 `android/app/build.gradle` 配置 `signingConfigs`，当前 `build-apk.bat` 产出的是 Debug 签名包，仅供装机测试。

iOS 需 macOS + Xcode，命令为 `npx cap add ios` 后在 Xcode 构建。`capacitor.config.json` 中 appId 为 `com.reptile.breeding`，webDir 为 `www`（由 `node tools/sync-web.mjs` 生成，不含服务端/测试/工具代码）。

App 内数据存储 native 侧方案见「六、架构与扩展」的 SQLite 适配层说明；在适配完成前，WebView 内的 IndexedDB 同样满足本地存储诉求，备份包两端通用。

> 📄 **更新日志（外置正文）**：应用内「更多 → 关于 → 版本信息」弹窗展示的内容，全部来自项目根目录的 **`更新日志.txt`**。
> 直接编辑该文件即可更新 App 内的更新说明与关于正文，**无需改动任何代码**。文件格式：`## 关于` 段为关于卡片正文，其余 `## 版本号` 段为更新条目（每行一条，以「·」开头更易读）。
> 构建时 `tools/sync-web.mjs` 会把它复制为 `www/release-notes.txt`（ASCII 文件名，避免中文名在 WebView fetch / APK assets 上的编码问题），并由 `server.js` 提供 `/release-notes.txt` 别名以便本地 Web 端调试。

> ⚠️ **构建顺序不可省**：`node tools/sync-web.mjs` 只把源码同步到 `www/`，还必须 `npx cap sync android` 才会拷贝进 `android/app/src/main/assets/public/`（APK 真正打包的目录）。漏掉 cap sync 会打出「版本号新、代码旧」的包。build-apk.bat 已固化五步流程；构建后可 `unzip -l app-debug.apk | grep assets/public` 核对。

## 四、关键业务规则实现

| 规则 | 实现位置与行为 |
|---|---|
| 日志时间 | `store.addLog` 固定 `nowStr()`，无任何手动入口 |
| 删除个体 | `removeAnimal`：级联清除照片/日志/蛋/关联待办；账单保留但解除关联；弹窗列明影响数量 |
| 备份原子性 | `db.atomicReplace`：单 IDB 事务内 clear + 全量写入，任一失败整体回滚，本机数据不损坏 |
| 导入时间戳 | 比对本机最近更新时间与备份导出时间，本机更新时强确认 |
| 基因删除 | 仅允许删除自定义基因（v2.5 起内置基因不可删除，`removeGene` 抛错守卫）；硬删除：从基因库移除，并同步从所有个体的 `geneIds` 中清除引用（提示受影响个体数） |
| 标签删除 | 允许删除，同步从所有个体 `tagIds` 移除并提示数量 |
| 物种删除 | 被个体引用即禁止（抛错提示数量） |
| 配对记录 | `pairing` 表：`participants` 规范为 `[母本, 父本]`（一母一父）+ 配对日期 + 结果（待观察/成功/未成功）+ 备注；个体详情页可按个体查看；删除个体时级联清理。v2.6 起新增/编辑窗口改为「物种 + 母本 + 父本」三个下拉（按物种与性别过滤，切换物种清空失效预选，提示当前物种可选数量）；v2.7 起母本/父本下拉除名称外同时显示个体编号与基因（格式「名称（编号）· 基因」，与蛋记录下拉一致） |
| 基因库恢复出厂 | `resetGenes` 仅重置基因表（清空+重建内置种子），不影响个体等其他业务数据 |
| 数据库升级 | `DB_VERSION` 只增不删：v2 增 `pairing` 表、v3 删 `morph` 品系表；升级不清除任何用户数据（`test/verify-upgrade.mjs` 8 项断言守护） |
| 爬箱唯一绑定 | `animal.cageId` 单字段；绑定新箱即换箱 |
| 待办自动生成 | `refreshAutoTodos`：爬箱清理（到期前 7 天可见）、蛋破壳（受精+预计日期）；建蛋时生成产后检查（同母本同批一次一条）；配对记录为**每只母本**生成产卵检查待办（+20 天，dedupeKey 去重，父本不生成；改期同步截止日，移除母本删除对应待办）。v2.1 起产卵检查待办只关联配对记录（不标记个体）；v2.6 起在首页/工单页点「查看关联」弹窗展示该配对记录（时间/物种/父母本均不可修改），用户确认配对结果与备注后点「确定」同步回配对记录；点「完成」则先弹「登记配对结果」（保存并完成），同步配对记录并完成待办 |
| 基因状态废止（v2.6） | 个体不再登记 `geneState` 字段（表单/详情/分享包/备份均不含该字段）；boot 时一次性迁移剥离存量数据中的残留字段（meta `geneStatesRemoved` 标记，只跑一次）；基因预测统一按基因的遗传类型取默认值（显性/隐性=纯合表现、不完全显性=单拷贝） |
| 蛋状态机 | 非受精/归档自动取消破壳待办；恢复受精自动重建待办 |
| 记账联动 | 购入价→自动支出；售出金额→自动收入（`countInStats` 跟随全局开关）；自动账单可手动删除 |
| 风险操作 | 全部二次确认弹窗；取消=提前 return |

## 五、内置数据与模型说明

- **箱体规格**（`schema.js` `CAGE_SPECS`）：A3 40×28×20 / A4 50×35×23 / A6 60×40×30 / R4 36×25×18 / R6 46×32×18（cm）。行业无统一公开尺寸，**这是默认预设值，改这里一处即可全局生效**；布局网格按 1 格=10cm 近似。
- **基因遗传类型**（v2.0 起仅此四类，多基因选育已取消、存量数据只读兼容）：显性 / 隐性 / 不完全显性（超级体）/ 复合。复合基因通过 `comboOf` 声明组分基因名，预测时按组分的「显现概率」的乘积推导复合显现概率。v2.2 起睫角内置 16 项：原色（显性，野生型基准，预测时选它等同于不选）、莉莉白/卡布奇诺/高速公路/紫貂（不完全显性，v2.4 起紫貂由显性改为不完全显性，双拷贝为超级紫貂）、缺黄/巧克力（隐性），以及 9 个复合基因——法布奇诺（卡布奇诺+莉莉白）、缺黄莉莉（缺黄+莉莉白）、缺黄卡布（缺黄+卡布奇诺）、缺黄紫貂莉莉（缺黄+紫貂+莉莉白）、猫屎咖啡（卡布奇诺+紫貂）、雪岳（莉莉白+超级卡布奇诺，组分含状态名故复合命名不会触发，按性状展示）、Highway莉莉白（高速公路+莉莉白）、紫貂缺黄（紫貂+缺黄）、紫貂莉莉（紫貂+莉莉白）。猪鼻蛇内置：北极（显性）、白化/无红/缺黄/康达/焦糖/薰衣草（隐性）。**内置基因定义每次启动经 `syncBuiltinGenes` 强制覆盖存量数据**（用户对内置基因的改动不保留，自定义基因不受影响）——v2.4 即借此把存量用户库中的紫貂覆盖为不完全显性；**v2.5 起内置基因不允许在产品内修改/删除**（仅自定义基因可编辑/删除，store 层 `updateGene`/`removeGene` 有守卫，基因库页不出现入口；「恢复出厂」可整体重置内置基因）。
- **预测模型**（v2.3 重写，公母双方各选 1 个基因，**不再选择携带状态**；v2.4 增互换按钮/隐前缀/逐段着色；v2.5 超级体性状改表达式）：点「开始预测」弹窗展示后代结果表（**概率 / 基因性状 / 基因名称** 三列，可导出 PNG 图片），「开始预测」旁的「🔄 互换」按钮一键对调公母已选基因。单基因按孟德尔分离比**精确枚举**所有后代基因组合（非蒙特卡洛），状态按遗传类型取默认值（显性=表现、隐性=纯合表现、不完全显性=单拷贝、复合=拆解后各组分的默认值），如 莉莉白(单拷贝) × 原色 → 50% 莉莉白 / 50% 原色。**复合基因拆解**：父母本任一方选择复合基因时，按 `comboOf` 拆解为组分基因分别参与孟德尔计算（如 母本缺黄莉莉 = 缺黄 + 莉莉白，父本缺黄卡布 = 缺黄 + 卡布奇诺，则两方按 缺黄×缺黄、莉莉白×卡布奇诺 计算，后代再组合出新复合性状）；**基因性状列始终呈现拆分后的组分基因名**（缺黄+莉莉白），复合登记名只出现在基因名称列。**超级体命名**：两个相同不完全显性基因预测，双拷贝（纯合子）结果的名称加「超级」前缀（如 卡布奇诺 × 卡布奇诺 → 名称 超级卡布奇诺），基因性状列则记为表达式「卡布奇诺+卡布奇诺」，并给出 ⚠️ 健康风险提示。**隐性携带标注**：隐性基因需父母双方都携带才显现，仅一方携带时后代「携带不表现」——此类行的基因名称加「隐」前缀（如 原色 × 缺黄 → 隐缺黄；缺黄 × 莉莉白 → 莉莉白+隐缺黄 / 隐缺黄）；含超级体或隐携带的行不套用复合基因登记名（避免掩盖携带状态）。**逐段着色（v2.5）**：仅「超级」段标红、「隐」段标蓝，名称中的其余基因段不着色（如 莉莉白+隐缺黄 仅「隐缺黄」蓝、缺黄+超级莉莉白 仅「超级莉莉白」红）；导出 PNG 同步逐段着色。复合基因命名规则：组合性状的基因名集合与基因库中某复合基因的 `comboOf` 完全一致且无隐携带/超级体时采用其登记名，否则沿用性状拼接。蛋详情按父母本已登记基因走同一引擎。结果仅供繁育参考。
- **收入颜色约定**：收入=红、支出=绿（中式记账习惯）。

## 六、架构与扩展

- **数据层双实现**：`db.js` 为 IndexedDB 实现；App native 化时实现同接口的 SQLite 适配（`@capacitor-community/sqlite`），`store.js` 无需改动。备份/分享 JSON 与后端存储无关，天然互通。
- **单位口径**：内部统一存储 g / cm，切换单位只影响显示与录入换算。
- **偏好 vs 数据**：单位/主题存 localStorage（设备级，不随备份迁移），业务数据全部走 IndexedDB 并参与备份。
- **UI**：桌面侧边栏 + 移动底部 Tab（≥960px 断点）；底部导航顺序为「蛋管理 / 个体管理 / 首页（居中凸起主按钮）/ 配对记录 / 更多」（v2.7 起原「记账」位改为「配对记录」、「个体」改名「个体管理」，「记账」改名「记账报表」迁至「更多」页原配对记录位置），爬柜等次级入口收在「更多」页；明暗双主题全套变量。
- **全面屏适配**：Android `MainActivity` 以 edge-to-edge 运行，将系统栏 insets 以 CSS 变量 `--safe-area-inset-*` 注入 WebView（样式层 fallback 到 `env()`），顶栏/底栏/Toast 均避让状态栏与手势区；状态栏图标明暗随主题联动；返回键/手势返回走 `__rbBack`（关弹窗 → 历史返回 → 回首页 → 才退出）。
- **原生启动页**：`MainActivity` 启动时以 `addView` 在 `android.R.id.content` 上覆盖一层原生视图（不依赖 Web 资源），正中为 logo（`@drawable/splash_logo`，取自 `logo-g.png`）+ 应用名「养个爬」+ 副标「让每个爬友便捷养爬」+「本软件全功能免费，若支持可捐助」+ **「一键捐助」按钮**（v1.0.0 起由纯文本链接改为品牌绿圆角按钮，点击经 `openExternalUrl()` 以 `ACTION_VIEW` 打开爱发电主页 `https://afdian.com/a/c7h31`）。**时序**：3 秒后右上角「跳过」按钮淡入并开始 5 秒倒计时（按钮文字实时显示「跳过 (5)」→「跳过 (1)」），倒计时结束自动进入应用；用户手动点击「跳过」可立即进入。跳过按钮实现为 `TextView`（需 `instanceof TextView` 转型才能 `setText`，声明为 `View` 会编译失败）。

## 八、已知边界与建议

1. R4/R6 尺寸为行业惯例预设，请按你的实际箱体校正 `schema.js`。
2. 基因库为常见品系精选，自定义基因请在「基因库」页补充（含遗传方式选择）。
3. 基因库为常见品系精选，自定义基因请在「基因库」页补充（含遗传方式选择）；复合基因需在「复合基因组分」中声明组分（如 卡布奇诺、莉莉白），组分未声明时按隐性近似估算。
4. IndexedDB 容量通常数百 MB~数 GB，照片已压缩（单张 ≤0.7MB），常规使用无压力；长期大量照片建议定期导出备份后清理。
5. iOS 打包需要 macOS + Xcode；安卓在 Windows 上装 JDK + Android SDK 即可出 APK（一键脚本 `install-build-env.bat` + `build-apk.bat`，构建在 `C:\rb-build` 英文路径进行，见快速开始路线 B）。
6. 项目路径含中文时 Gradle 直接构建会报 IOException，`build-apk.bat` 已自动迁移到纯英文路径并排除 `.gradle`/`build` 缓存目录。
7. `www/` 目录由 `node tools/sync-web.mjs` 生成，请勿手改；每次同步会整体重建。
